# Assets Directory

This directory is for storing static assets for the Holy Cross School Kabuganj website.

## Structure

- `/images` - For all image assets
  - `/logo` - School logo variations
  - `/hero` - Hero section images
  - `/staff` - Staff and faculty photos
  - `/campus` - Campus and facility photos
  - `/events` - Event photos
  - `/gallery` - General photo gallery
  - `/icons` - Custom icons

- `/fonts` - Custom fonts (if not using Google Fonts or other CDN)

- `/documents` - PDFs and other documents
  - `/forms` - Downloadable forms
  - `/policies` - School policies
  - `/curriculum` - Curriculum documents

## Usage Guidelines

1. **Image Optimization**
   - All images should be optimized for web use
   - Use appropriate formats (JPEG for photos, PNG for graphics with transparency, SVG for icons)
   - Consider providing multiple sizes for responsive design

2. **Naming Convention**
   - Use lowercase letters
   - Use hyphens instead of spaces
   - Be descriptive but concise
   - Example: `campus-library-exterior.jpg`

3. **Metadata**
   - Include alt text for all images when implementing
   - Document the source/copyright information if applicable

## Adding New Assets

When adding new assets:
1. Place them in the appropriate subdirectory
2. Optimize them for web use
3. Update this README if creating new categories
4. Update any relevant component files to use the new assets
